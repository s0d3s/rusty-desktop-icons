# Python

Use the PyPI package to inspect layouts, animate icons and render frames from
Python. The native engine handles timing and GPU work; Python assembles requests
and consumes results.

Start with [installation](getting-started/installation.md) and a
[read-only desktop query](getting-started/quickstart.md). Use
[concepts](../concepts/index.md) for entity contracts and the pages below for
task-oriented code. The API reference is generated from the same stubs shipped
in the wheel, not maintained as a separate set of signatures.
